# e-plantShopping – Paradise Nursery Shopping Application

## Project Overview

**e-plantShopping** is a Paradise Nursery shopping application where users can explore indoor plants, browse plant categories, and add plants to a shopping cart.

## Main Features

- Paradise Nursery landing page with a **Get Started** button.
- Plant product listing with plant names, categories, prices, and images.
- Category filtering on the product listing page.
- Add-to-cart interaction for plant products.
- Shopping cart interface with quantity controls, item removal, and total calculation.

## Project Files

- `App.jsx` – Main landing page and navigation to the product listing.
- `AboutUs.jsx` – Company information.
- `App.css` – Landing page styling and background image.
- `ProductList.jsx` – Plant product listing and category filters.
- `CartSlice.jsx` – Shopping cart state and reducer actions.
- `CartItem.jsx` – Shopping cart display and quantity controls.
